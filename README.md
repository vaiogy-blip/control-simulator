# 控制系統模擬器

在電腦上把控制設備拖進畫布、接線，然後模擬整套系統的動作。第一版以「全功能主機」（CVIA-92 全功能無線車道型遙控主機）為核心。

## 直接使用

用瀏覽器（Chrome、Edge）打開 `控制模擬器.html` 即可，不需安裝、不需網路。專案會自動存在瀏覽器裡，也可以按「儲存」存成 `.json` 檔，之後用「開啟」載入。

## 操作

1. 左側點選設備加入畫布，拖曳設備移動。右側「圖示大小」可調整單一設備（50%~200%），也可一鍵套用到全部設備；上方「顯示」可縮放整個畫布。
2. 從一個端子（圓點）拖到另一個端子接線，接線不分方向。接線會自動走直角線、避開設備；同一個節點的線分岔處會畫節點圓點。把接線拖到另一條線上，會在落點加一個節點並接在一起；左側「配線」也可直接加節點。
3. 自己決定走線：在端子上點一下（不要拖），再到空白處逐一點出轉折點（會自動對齊成水平或垂直），最後點目標端子或另一條線完成；Backspace 退回上一點，Esc 取消。已接好的線，選取後拖曳線上的小方塊可移動那一段，路徑就改成手動；接線面板的「恢復自動走線」可改回自動。節點可以拖到想要的位置。
4. 點選接線可改線色（預設：接電源正極紅、負極黑，其他藍），按 Delete 刪除。
5. 電路依實際接線判斷：負載（繼電器線圈、燈、喇叭）兩端要分別接到同一台電源的正、負極（可經過接點）才會動作，額定電壓不符時不動作並顯示「電壓不符」；主機 KEY、SENSOR 與柵欄機的上停下是乾接點，和共點接通就動作。串聯、並聯直接用接線完成。
6. 直接在設備上按遙控器、按鈕、刷卡、讓車通過，模擬會自動開始，整個動作跑完後自動暫停（動作中再操作，會等全部跑完才暫停）。也可以按「播放」（或空白鍵）手動播放、暫停，手動播放會一直跑到再按暫停。
7. 點選全功能主機，右側可用虛擬鍵盤照實機輸入，格式為「功能#設定值米」、不需密碼（例如 `7#10米`、`11#11米`），或用設定面板調整參數，主機會以嗶聲回應。主機圖示可選「接線圖風格」（顯示目前參數清單）或「實機外觀」。
8. 下方「接點動作紀錄」依時間列出每個接點、線圈、主機輸入輸出的動作與主機嗶聲，可只看選取的設備。

## 設備

| 類別 | 設備 |
|---|---|
| 控制主機 | 全功能主機（端子台：KEY 白紅黃綠、SENSOR COM／IR／SM、馬達 上停下共、RELAY NO／COM） |
| 遙控 | 直立式五鍵遙控器：左側 ▲■▼F，右側 S（無線，需先用 1# 登錄） |
| 電源 | DC 或 AC，電壓可選常用值或自訂；端子 +／−（DC）或 L／N（AC），可開關，正負極直接接通會顯示短路 |
| 輸入設備 | 押扣按鈕、切換開關、地感線圈、紅外線、卡機：一律有 COM、NO、NC 三個端子 |
| 輸出設備 | 柵欄機（上停下共乾接點、上限／下限極限開關接點；馬達直驅或脈衝觸發）、指示燈（+／COM）、紅綠燈（紅／綠／COM）、警報喇叭（+／COM） |
| 繼電器類 | 繼電器、計時繼電器 TDR（TON/TOF/TP）：可選 1~4 組接點，端子依 8 腳／14 腳繼電器座編號（第 g 組 NC＝g、NO＝g+4、COM＝g+8，線圈 14＋、13−），線圈電壓可選 |
| 配線 | 節點（分岔、轉接） |

## 全功能主機的端子

依《CVIA 按裝說明》接線圖：

| 端子 | 用途 |
|---|---|
| KEY 白／紅／黃（綠＝共） | 外部押扣：白＝上、紅＝停、黃＝下，與綠（共）接通即動作。感應卡機的 RELAY（NO、COM）接 KEY 的白與綠 |
| SENSOR 紅外線（IR）、COM | 紅外線防壓／防盜（紅外線的 NO、COM 接這裡） |
| SENSOR SM、COM | 分段定時（接定時器）／防盜／防煙 |
| 馬達 上／停／下、共 | 主機內部接點，動作時與「共」接通。切換開關「机」通電整個行程（傳統門）；「電」只送 14# 秒脈衝（快速門、電子式馬達或外接繼電器） |
| RELAY（NO／COM） | 第 4 顆繼電器的乾接點：電鎖、電源開關、警報、警示燈、紅綠燈共用 |

## 主機嗶聲

| 情況 | 嗶聲 |
|---|---|
| KEY 外部接點動作（已用 11# 開啟） | 每次一短聲 |
| 紅外線接點動作（遮斷） | 每次一短聲 |
| SM 分段定時觸發 | 一長音＋兩短音，門開啟並保持 |
| SM 分段定時解除 | 一長音，再依 7# 秒數倒數後送「下」 |
| 7# 自動關門倒數 | 剩 5 秒起每秒一短聲，嗶完第 5 聲才送「下」 |
| 設定成功／完成／錯誤／逾時 | 長音／一聲／三聲／五聲 |

已向使用者確認：KEY 外部押扣出廠預設關閉，需用 11#11 或 11#22 開啟（2A1B 模式下紅＝停為常閉，接押扣的 NC）；警報、警示燈、紅綠燈都由第 4 顆 RELAY 動作；尚未用 25# 定義的區段，遙控器照預設 ▲上、■停、▼下、F 斷電、S 不使用。

## 全功能主機已模擬的功能

1#~4# 遙控器新增、刪除、暫刪、恢復；6# 暫停使用與分段定時；7# 自動下降；8# 行程時間；9# 自動斷電；11# 主機功能（上下裝反、聲響、外部押扣 2A1B/3A、RELAY 同步、偵煙單鍵循環、紅綠燈）；12# 紅外線 1~4、6、7；13# 2 秒馬達保護；14# 上停下吸持；15# 第四繼電器吸持；16# 緊急求救；17# 防盜與警示燈；18# 二段式關門；20# 還原預設；21# 刪除全部遙控器；23# 紅外線關門警報；24# 警報時間；25# 按鍵功能（遙控器五鍵與外部押扣）；管理型遙控器（序號 2951~2999）；8 秒未操作自動離開設定。

19#、22#、26#~31# 可以輸入並記錄，但尚未模擬其功能。

依使用者實際用法：設定指令不輸入密碼（例如 `11#11米`）；遙控器按鍵只用 25# 定義，10# 與 5# 不使用。25# 每個區碼 10 碼，依序為 ▲■▼F S 各 2 碼（舊的 8 碼格式會自動補 S＝00）。

## 待確認的假設

說明書寫得簡略的地方，目前採用以下假設，請依實機修正：

- 切換開關「机」：每次上或下命令，方向繼電器通電完整的 8# 行程時間；8# 為 0 時通電到按停或反向。
- 切換開關「電」：上停下繼電器只吸合 14# 秒數，主機用 8# 行程推算何時到位（自動下降從那時開始計時）。
- 14#、15# 預設值設為 1 秒（說明書未列）。
- 6#2 分段定時：SM 導通期間門保持開啟、不自動下降；SM 斷開時嗶一長音並依 7# 倒數關門（7# 為 0 時直接關門）。
- 主機、紅外線、地感線圈、卡機視為自行供電，不必另外接電源；它們的輸出都是乾接點。
- 負載額定電壓容許 ±15%，交直流要相符；設「不限」時不檢查。
- 柵欄機的上停下是乾接點輸入；馬達直驅時接通期間才移動。
- 紅綠燈（11#27）在門全開時 RELAY 吸合（NO 接綠燈）。
- 紅綠燈模式（使用者說明）：上／下繼電器吸合 14# 秒數跑完一次完整循環，最後 5 秒每秒嗶一聲；循環中同向不延長、反向／停／紅外線都不改變動作；跑完復歸，不自動下降，等下一次觸發。上、下的 NC 在這個模式會個別用來接燈。
- 紅外線啟用（12# 任一模式）且遮斷時，主機拒絕下降，自動下降與二段關門倒數會重新計時。
- 二段式關門（12#3）：車輛離開紅外線後依 18# 秒數關門；關門中再遮斷則停止並彈升。
- 「停」命令同時解除長鳴警報。
- 13# 防空轉、上下互動式、吸持隨按鍵、持續按 2 秒斷電、RF 同步輸出尚未模擬。

## 開發

需要 Node.js 18 以上。

```
npm install
npm run dev      # 開發伺服器
npm test         # 執行模擬引擎測試
npm run build    # 輸出單一檔案 dist/index.html
```

程式結構：

- `src/engine/`：模擬引擎（不依賴畫面）。`sim.ts` 掃描週期 50 ms，每個週期用接線與閉合的接點求出各節點，判斷負載通電與乾接點接通，並記錄接點動作；`host.ts` 是 CVIA-92 主機，`devices.ts` 是其他設備，`examples.ts` 是內建範例。
- `src/ui/`：畫面（React + SVG）。`layout.ts` 各設備外框與端子位置，`route.ts` 直角佈線（A* 避開設備、分岔節點），`DeviceBody.tsx` 設備圖示，`EventLog.tsx` 接點動作紀錄。
- 專案檔格式 version 2；開啟舊版（version 1）檔案時保留設備、移除接線。
